## A cidade é sua história

Rocha Roleplay é uma experiência de roleplay brasileira para **GTA San Andreas** no **SA-MP para Android**. Entre na cidade, construa sua trajetória, conheça pessoas e participe de uma comunidade que transforma cada sessão em uma nova história.

Este é o repositório público oficial para distribuição das versões do cliente. Aqui você sempre encontrará os APKs lançados manualmente, notas de atualização e versões anteriores quando disponíveis.

## Instalação

1. Abra a página de [Releases](https://github.com/fishixz/RochaRoleplay/releases).
2. Baixe o APK da versão mais recente.
3. Instale ou atualize o aplicativo no Android.
4. Abra o Rocha Roleplay, entre com sua conta e pressione **Jogar**.

> Se o Android solicitar permissão para instalar apps desconhecidos, autorize apenas o aplicativo usado para abrir o APK.

## Atualizações

O launcher pode baixar atualizações de dados automaticamente, conforme a configuração escolhida no próprio aplicativo. As atualizações do cliente APK ficam disponíveis nesta página através das Releases.

| Canal | Uso |

| Release mais recente | Versão recomendada para jogar |
| Releases anteriores | Retorno a uma versão anterior, quando necessário |

## Compatibilidade

- Android 8.0 ou superior
- Dispositivo com arquitetura ARM64 ou ARMv7
- Espaço livre para os arquivos do GTA San Andreas e do servidor
- Conexão estável com a internet

## Comunidade

O Rocha Roleplay é feito para quem gosta de cidade viva: empregos, negócios, veículos, encontros inesperados e histórias que continuam quando você sai da tela. Acompanhe os canais oficiais da comunidade dentro do launcher para novidades e suporte.
